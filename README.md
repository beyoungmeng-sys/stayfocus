# 短视频提醒 V2

目标：在用户开始进入“连续刷短视频”的状态时提醒，而不是简单限制某个 App 的使用时长。

## V2 行为
- AccessibilityService 后台监听
- 连续上滑检测
- 15 秒行为窗口
- 快速重复上滑增加更多分数
- 常见视频 App 作为辅助信号
- 当前无障碍 UI 树中的视频/短视频关键词作为辅助信号
- 达到 8 分提醒
- 提醒冷却 60 秒
- “退出”返回桌面
- “我就是要刷”继续
- 不联网、不上传屏幕内容

## 编译
使用 Android Studio 打开工程，等待 Gradle Sync 完成，然后 Build > Build APK(s)。

注意：不同 Android App 暴露的无障碍 UI 信息不同，所以这是可运行的 V2 原型。实际使用时应根据你的手机和常用 App 的 AccessibilityEvent 数据继续调参。
